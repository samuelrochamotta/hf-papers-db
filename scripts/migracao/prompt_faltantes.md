# Justificativa retroativa — aprovados do backfill

Este paper foi aprovado durante a migração do histórico, sem que uma justificativa
tivesse sido escrita na época — o registro carregava só a marca de importação. O
veredito abaixo **já foi decidido por outra pessoa** e é fato consumado. Sua única
tarefa é escrever a justificativa *daquele* veredito: nunca reavalie, nunca discorde,
nunca sugira outro.

**Veredito já decidido:** {VEREDITO}

Para lembrar o que cada veredito significa (não decida de novo, só use como guia
de vocabulário):

- `estrito` — muda uma decisão ou entrega artefato adotável por quem não treina
  modelo: padrão arquitetural reproduzível, biblioteca ou infraestrutura aberta,
  achado que invalida prática corrente, vulnerabilidade explorável, ou técnica de
  avaliação transferível.
- `amplo` — informa a decisão mas não entrega o que adotar: benchmark, survey,
  relato de sistema em escala não reproduzível, framework conceitual sem
  instrumento.
